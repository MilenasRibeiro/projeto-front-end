# projeto-front-end
Sistema Inteligente Financeiro

Sobre o Projeto
Sistema Inteligente Financeiro é uma plataforma desenvolvida para auxiliar no gerenciamento financeiro de empresas, negócios e usuários que desejam acompanhar indicadores, relatórios e informações estratégicas em um único ambiente.
O sistema possui uma interface moderna, organizada e intuitiva, permitindo acesso rápido às principais funcionalidades através de menus e dashboards interativos.

Objetivo do Projeto
O principal objetivo do projeto é oferecer:
Controle financeiro inteligente
Visualização de métricas e indicadores
Organização de relatórios financeiros
Melhor tomada de decisão
Interface moderna e responsiva
Navegação simples e prática

Como Executar o Projeto
1️⃣ Clone o repositório
git clone https://github.com/seuusuario/seurepositorio.git


2️⃣ Acesse a pasta do projeto
cd seurepositorio


3️⃣ Configure o banco de dados
Crie um banco de dados no MySQL
Importe o arquivo .sql
Configure as credenciais no arquivo config.php
Exemplo:
$host = "localhost";
$user = "root";
$pass = "";
$db = "sistema_financeiro";


4️⃣ Execute o projeto
Utilize:
XAMPP
WAMP
Laragon
Depois acesse:
http://localhost/projeto
